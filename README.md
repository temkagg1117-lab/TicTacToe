2. turtle санг ашиглан график талбар болон тэмдэгтүүдийг зурсан.
Хүн–хүн болон хүн–компьютер гэсэн хоёр горимтой.
Тоглогчийн оролтыг input() функцээр авч, зөв эсэхийг шалгадаг.
Компьютерийн нүүдэл нь санамсаргүй байдлаар сонгогддог.

3. График сайжруулалт
X тэмдэг нь улаан өнгөөр, O тэмдэг нь цэнхэр өнгөөр ялгаатай.
Хожил гарсан тохиолдолд ногоон шугам зурж ялалтын дарааллыг тодруулдаг.
Энэ нь тоглоомыг илүү ойлгомжтой, хэрэглэгчид ээлтэй болгож өгсөн.
4. Тоглоомын явц ба мессежүүд
Тоглоом дуусахад “Тоглоом дууслаа!” гэсэн тодорхой мессеж гардаг.
Хэрэв бүх нүд бөглөгдөөд хожил гараагүй бол “Тэнцэл!” гэж мэдээлнэ.
Хожсон тохиолдолд аль тоглогч хожсоныг дэлгэцэнд харуулдаг.
5. Бонус нэмэлт 
Тоглоом дууссаны дараа хэрэглэгчээс “Дахин тоглох уу?” гэж асуудаг.
Хэрэв “y” гэж хариулбал талбар цэвэрлэгдэж, тоглоом дахин эхэлнэ.
Энэ нь тоглоомыг олон удаа туршиж үзэх боломж олгож, илүү хэрэглэгчдэд ээлтэй болгосон.
